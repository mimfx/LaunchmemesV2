# LaunchmemesV2

Independent Solana token-launchpad interface built with React and Vite.

## Development
```bash
npm install
npm run dev
```

## Current status
- Responsive launchpad shell and navigation
- Token discovery preview with search and sample rows
- Guided token creation form (preview only)
- Liquidity workspace and X Tracker placeholders
- Wallet selection modal (wallet adapters not connected yet)

## Safety
Market figures are sample data. This version does not create tokens, submit transactions, or manage liquidity. Live blockchain functionality will be added after wallet, program, RPC and transaction flows are implemented and tested.
